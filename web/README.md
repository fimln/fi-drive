# fi-drive: frontend

Frontend React + Vite. Lihat [README utama](../README.md) untuk pengaturan lokal, autentikasi, pengujian, dan deployment.

```powershell
npm ci
npm run lint
npm run build
```

Hasil build ada di `dist/`. Identitas login disediakan Azure Static Web Apps; frontend tidak menyimpan password atau token pengguna.
